# Secure Paste

Статическая страница [`/copycat/`](./copycat/) предназначена для публикации через GitHub Pages. Она не использует backend, API, базу данных, browser storage, сторонние библиотеки или сетевые запросы после загрузки собственных файлов.

## Архитектура

- Сообщение кодируется в UTF-8 bytes и дополняется нулевыми байтами до bucket размером 256, 512, 1024 байта и далее до 64 KiB. Первые четыре bytes зашифрованного блока содержат исходную длину. Это частично уменьшает утечку длины, но не скрывает её полностью.
- Для каждой записки браузер создаёт **ровно 32 случайных bytes** через `crypto.getRandomValues`. Эти bytes напрямую импортируются как raw AES-256 key: «пароль» — это Base64URL-представление случайного 256-битного AES-ключа, а не человеческий пароль; KDF/PBKDF2 не применяется.
- Браузер также создаёт новый случайный 96-битный nonce (12 bytes) через `crypto.getRandomValues` и шифрует padded bytes с помощью Web Crypto API: AES-256-GCM, стандартный 128-битный authentication tag и AAD `copycat:v1`, который аутентифицирует версию/формат.
- Fragment имеет формат `v1.<nonce-base64url>.<ciphertext-base64url>`. В нём находятся только публичные nonce и ciphertext; ключ не входит ни во fragment, ни в query string, pathname или запрос к серверу. Fragment не передаётся GitHub Pages при HTTP-запросе страницы.
- Перед Base64URL-декодированием длина fragment ограничивается 100 000 символами. Декодер проверяет структуру, размеры, tag GCM и padding. Неверный ключ, nonce или ciphertext не отображает данные.
